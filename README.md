I was working on an app in MAUI, I had to set it aside for a couple of months and when I went back to it, I realized I had no idea what the following line meant.  <FontImageSource FontFamily="FluentSystemIcons-Filled" Glyph="&#xf3b0;"/>
I mean, I could read it and knew it was a glyph character, but I didn't know what character "&#xf3b0;" referred to.  So, I asked Copilot if there was an easy way of making that value 'readable' in a review setting.  You see it done in
other contexts, but I haven't seen it in MAUI, at least not on a large scale.
After a little work, and a lot of help from Copilot, I came up with FontExamine (it's actually Font Explorer in the window).  I haven't added a page to modify the settings, so you will have to change them manually if you clone this repository.  I didn't include the FluentSystemIcons fonts, I found them on Github and I don't 'own them' so I don't think I can distribute them.  I searched something like 'Microsoft Fluent System Icons'.
